# SEED-CF-02 — Autogen containment + category fixture types

**Change:** `layout-client-feedback` · **Status:** Pending review

## Goal
Ensure autogenerated shelves never overflow the drawn fixture polygon and allow category-specific fixture types (e.g. storage for vegetables).

## Scope
- Filter autogen output through `entityInsideLayout`; never persist outside entities
- Extend category mix with `fixtureType` (shelf, gondola, rack, storage)
- Default mapping: produce/vegetable → storage; grocery → gondola; fallback → shelf
- Smart Generate UI: optional fixture type per category row
- Autogen toast/report: skipped outside count

## Constraints
- Reuse existing `FIXTURE_TYPES` from reference catalog
- Containment validation must match manual drag rules (LD-02 baseline)

## Acceptance criteria
- [ ] L-shaped polygon autogen → zero containment violations
- [ ] Fresh produce category row → shelves created as `storage` when configured
- [ ] Skipped-outside fixtures never appear in saved layout
- [ ] Manual palette still places all fixture types

## Evidence
- API test: autogen on irregular polygon
- Manual Smart Generate with produce category

## Risks & rollback
- Medium: autogen density may drop on tight polygons; document skipped count in UI
