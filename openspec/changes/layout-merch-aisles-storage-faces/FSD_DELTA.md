# FSD delta — layout-merch-aisles-storage-faces

Target: `Docs/FSD_ShelfPilot.md` (apply after client verification)

## Epic D — Catalog → Layout merchandising (MODIFY)

- When a category is assigned to a shelf face, the Merchandising planogram picker lists **all products** in that category and its **child categories**, including products added after layout open (refresh on shelf select + manual Refresh).
- Face **B** category mapping is independent of Face **A** on dual-face fixtures.

## Epic E — Planogram / facing suggestions (ADD)

- Selecting a product on a shelf shows **suggested arrangement**:
  - **Front facings** (width)
  - **Depth facings** (backward / backstock)
  - **Levels** (vertical stack)
- Suggestions derive from shelf dimensions and product attributes (`widthMeters`, `heightMeters`, `depthMeters`); defaults apply when attributes missing with an explicit UI hint.

## Epic C — Layout canvas / aisles (MODIFY)

- Autogenerated **aisles render visibly** on the 2D canvas (distinct fill, border, label) when inside the fixture polygon.
- Aisles overlapping shelf footprints are not placed (corridors only in walkable gaps).

## Epic F — Fixture types / dual-face (MODIFY)

- **Storage** fixtures are **double-sided**: display numbers **nA** and **nB**; each face supports independent category and planogram mapping (same model as gondola).

## OpenAPI (additive)

- Planogram preview response: `maxDepthFacings`, `productDepthMeters`, `shelfDepthMeters`, `suggestedLevels` (already partially documented if preview route exists).
