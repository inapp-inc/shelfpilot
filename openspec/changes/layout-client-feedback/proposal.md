# Proposal: Layout client feedback — envelope, autogen, UX & review workflow

**Status:** Approved / Implemented 2026-07-21

**Source:** Client presentation feedback (2026-07-21), following `layout-dimensions-rotation-shelf-bays`.

## Summary

Seven client-requested improvements to the layout editor, autogenerate behaviour, canvas UX, properties panel, and approval workflow.

## Client requests (traceability)

| # | Client ask | Problem today |
|---|------------|---------------|
| 1 | On **Apply area**, persist and show **full store dimensions** in a **distinct colour** alongside the drawn fixture zone | Apply sets polygon AABB as `widthMeters`/`depthMeters`; original store envelope from layout create is lost; only one boundary colour on canvas |
| 2 | **Autogenerated shelves must not overflow** the drawn line; support **different shelf types** per category (e.g. storage for vegetables) | Containment exists but overflow still reported; autogen uses one shelf template (shelf/gondola) regardless of category |
| 3 | Editor should **fit on screen** without body scroll; optional **zoom to area** (e.g. pick category → focus canvas) | Side rail requires page scroll; canvas stage grows; no focus/zoom-to-selection by category |
| 4 | When a shelf is selected, show **shelf name** on the right **Properties** panel | Panel shows generic label/type; no editable name field prominent |
| 5 | **Properties / Merchandising / Zones** tab alignment broken when on Merchandising | Tab bar misaligns when merch panel content is tall or scrolls |
| 6 | **Draw polygon then resize** it on canvas (not only click vertices once) | Draw mode adds vertices; Apply is one-shot; no vertex/edge drag after apply |
| 7 | **Rejection comment**; hide **Submit for review** after submit until changes; hide **Approve** until a new update | Reject is one click with no comment; action buttons always visible regardless of status/dirty state |

## Deliverables

### 1. Store envelope + fixture zone (dual boundary)

- Preserve **store envelope** (`storeEnvelope`: rect from layout create or explicit outer bounds) separately from **fixture polygon**.
- On Apply area: save drawn polygon as fixture zone; render **outer envelope** (full store W×D) in a **secondary colour** (e.g. slate dashed) and **inner polygon** in existing crimson fixture-zone style.
- Meter bar shows both: `Store 20×15 m · Fixture zone 14×10 m`.

### 2. Strict autogen + category fixture types

- Packer/autogen: **zero tolerance** for shelves/aisles outside polygon; increase post-gen validation and skip reporting.
- **Category → fixture type** mapping in Smart Generate (and optional manual override): e.g. Fresh Produce → `storage`, Grocery → `gondola`, default → `shelf`.
- Palette remains available for manual placement of all types.

### 3. Viewport-fit editor + focus zoom

- Editor layout: canvas + side rail **fit within viewport** (no document body scroll for rail tabs).
- **Fit to view** on open / after Apply (scale canvas to available height).
- **Focus control** in meter bar: dropdown of categories (mapped on layout) + “Selection” → pan/zoom canvas to bounding box of shelves/aisles for that category.

### 4. Shelf name in Properties

- Properties panel (shelf selected): show **editable name/label**, display number, type, dimensions (read-only summary).

### 5. Side rail tab alignment fix

- Fix CSS/layout so tab strip stays fixed width/aligned; merch panel scrolls inside `.editor-rail-body` only.

### 6. Resizable polygon floor area

- **Edit area** mode: select polygon → drag vertices and edge midpoints to reshape; Apply/Save commits.
- Optional: axis-aligned bounding resize handles on polygon AABB for quick adjust.

### 7. Review workflow gating + rejection comments

- **Reject** opens modal requiring **comment**; persist `reviewComment` (+ `reviewedAt`, `reviewedBy`) on layout.
- Designer sees rejection comment when status = `rejected`.
- **Submit for review**: visible only when `draft` or `rejected`, or when layout **dirty since last submit** (content hash / `updatedAt` vs last version snapshot).
- **Approve / Reject**: visible only when `in_review` and approver has not acted on **current submitted version**; after approve/reject, hidden until designer edits and resubmits.

## Success criteria

- Apply irregular polygon inside 20×15 m store → **outer envelope** visible in second colour; fixture zone unchanged semantically.
- Generate on L-shaped polygon → **0** shelves outside dashed line; produce category rows use **storage** type where configured.
- Open layout editor on laptop → **no body scroll** to reach Merchandising tabs; Focus → “Fresh Produce” zooms to those shelves.
- Select shelf → Properties shows **editable name** + `#displayNumber`.
- Merchandising tab: tabs stay aligned when scrolling product list.
- Edit area: drag polygon vertex after apply; save persists.
- Reject requires comment; Submit hidden after submit until edit; Approve hidden after approve until resubmit.

## Non-goals

- Multi-floor stores / multiple polygons per layout (v1: one fixture polygon + one envelope).
- Full BIM/CAD polygon boolean ops.
- Email notifications on reject (comment stored in app only).
