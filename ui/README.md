## SDD rule

All React UI work in `codebase/web` MUST match this reference for layout, spacing, brand, and interaction patterns. API wiring uses `Docs/openapi.yaml`; visuals use `ui/`.

Do not regenerate UI from scratch when this file exists — port and refine from it.
